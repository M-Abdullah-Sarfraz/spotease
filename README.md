# Python Django Web Development Project

## Overview
This project is a web application developed using Python and Django framework. It demonstrates solid skills in software and web development with a focus on backend logic, database integration, and front-end rendering. The project is designed to showcase practical knowledge gained during my Computer Science degree and further enhanced through advanced coursework and hands-on experience.

- Built with Python and Django framework
- User-friendly interface with dynamic content rendering
- Secure and scalable backend architecture
- Database integration using Django ORM
- Modular and reusable codebase following best practices
- Responsive design for desktop and mobile devices

## Installation

1. Clone the repository:
   
   [git clone https://github.com/M-Abdullah-Sarfraz/spotease]
   cd spotease
   
Create a virtual environment and activate it:

python -m venv venv
source venv/bin/activate   # On Windows use: venv\Scripts\activate

Install the required packages:

pip install -r requirements.txt

Apply migrations:
python manage.py makemigrations
python manage.py migrate

Run the development server:
python manage.py runserver
Open your browser and navigate to http://127.0.0.1:8000
